# Reproducibility
Install dependencies with `python -m pip install -r 07_REPRODUCIBILITY/requirements.txt`. Run `python 07_REPRODUCIBILITY/extract_and_measure.py` from the package or any working directory. It sequentially decodes source, exports full-resolution selected PNGs, crops, contact sheets and fresh measurements. The historical scripts are preserved from previous forensic passes with input/output paths made portable. They retain original thresholds, crop assumptions and methods; their outputs are not universal ground truth. Run each separately with Python and inspect output. The source video is required. Versions and decoder differences may change minor results. No external API or network required after dependencies are installed.

Historical methods: fana.py frame differences, template matches, switch segmentation, regional colour percentiles; geom.py SIFT similarity camera model; dense.py aligned avatar coverage; pass6.py light/dark manual landmarks and edge/saturation metrics; pass6motion.py aligned regional changes and swatch convergence; pass6opt.py alternative global models, sample luminance and threshold sensitivity. `extract_and_measure.py` is newly executed in this packaging pass; not all historical calculations were rerun. Frame metrics use downsampled luma, Sobel gradient /4, Gaussian blur 3×3 sigma .65, threshold >12, HSV S>=100; the original reported half-resolution film visual-activity table uses a different pipeline. Compare only within method. Full-resolution frames are decoded from compressed source, not lossless original animation renders.
