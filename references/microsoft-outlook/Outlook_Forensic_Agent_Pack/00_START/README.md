# Forensic World-Building Intelligence Pack v1.0
## Purpose
A portable research and production knowledge base derived from seven forensic analysis passes of the supplied Microsoft Outlook promotional animation. Designed for creative directors, motion designers, Blender/Three.js developers and autonomous production agents. No reconstruction has been performed. The source is a 63.766633 s compressed screen recording, not the original project.
## Start here
1. Read `AGENTS.md` in the package root before making any creative or production decision.
2. Read `01_MASTER/MASTER_SPECIFICATION.md`, then `01_MASTER/CREATIVE_CAUSALITY.md` and `01_MASTER/SHOT_ANALYSIS.md`.
3. Load `02_REGISTRIES/objects.json` and `scenes.csv`; use stable IDs and refer to the corresponding frames in `03_EVIDENCE/frame_index.csv`.
4. Read the measurements and `06_QA/EVIDENCE_AUDIT.md`. Values inherited from the seven passes are not automatically fresh verified measurements; reproducible calculations are supplied where available.
5. For new work, follow `05_AGENT/TRANSFER_WORKFLOW.md` and use `05_AGENT/PRODUCTION_BRIEF_TEMPLATE.md`. Apply `06_QA/QUALITY_GATES.md` before delivering.
6. Use the original reference video and `07_REPRODUCIBILITY` to resolve uncertainty. Do not invent missing values.
## Reading paths
- Art director: master → causality → transfer workflow → quality gates.
- 3D artist: master → object registry → source frames → material/camera notes → validation.
- Motion designer: scene registry → motion data → shot analysis → choreography grammar → QA.
- Agent: AGENTS.md → master → JSON registry → brief → quality gates. Use retrieval by object ID or shot ID.
## Evidence legend
V = verified source metadata or directly observed content; M = quantitative image-space measurement reported in the prior analysis; E = manually estimated coordinates or interpretation; P = proposed target or implementation, not recovered data; U = unresolved. Measurement tables copied from prior passes are clearly marked as inherited. Scripts and freshly generated outputs are independently inspectable. The precision of a displayed number does not imply the same precision in ground truth.
## Scope and rights
The source recording and extracted imagery are included as user-supplied reference evidence, not reusable licensed production assets. Do not assume redistribution or trademark permissions. For new public work, create original brand and geometry assets. The package is not an official Microsoft production specification.
