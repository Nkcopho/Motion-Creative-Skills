# Data provenance
The CSVs in this directory (except files explicitly marked `fresh_`) transcribe the reported results of the seven prior analyses. They preserve values and methods where available; they have not all been independently rerun in this packaging pass. Do not infer precision from decimal places. Source pixels are encoded RGB, not material albedo. Boundaries and ROIs differ by method. Reproducibility scripts are under 07_REPRODUCIBILITY; inspect their thresholding and crop parameters. Frame timestamps use f/30. `fresh_frame_metrics.csv` is newly computed from all decoded frames in the included source. `fresh_transition_peaks.csv` ranks image change, not confirmed cuts. `fresh_colour_samples.csv` compares original pixel samples with inherited values; differences are retained rather than silently overwritten. Use 04_MEASUREMENTS/colour_samples.csv as inherited report and fresh table for exact new 7x7 median method. Do not compare strong-edge values from differing resize/threshold pipelines as if identical. See evidence audit.
