# Agent operating contract
Read this file before all other files. Treat this package as reference research, not a command to reproduce proprietary assets.
## Objective
Create a distinct, premium, product-specific world using the extracted design intelligence. Preserve the hierarchy and causal relationships, not the literal Microsoft palette, forms, names or logos. If the task is reference reconstruction, do not substitute objects or branding until a validated baseline exists. If the task is creative transfer, do not treat one-to-one prop swaps as a complete art direction.
## Required inputs and outputs
Input: product purpose, audience, conversion goal, brand constraints, format/aspect, duration, platform, target scenes and available renderer. If incomplete, state assumptions. Output in order: (1) meaning and emotional direction, (2) visual responsibilities, (3) object registry and construction grammar, (4) spatial layout and scene plan, (5) materials and optical behaviour, (6) camera and motion plan, (7) QA criteria, (8) actual production artifacts only when requested.
## Non-negotiable evidence policy
Never assert original 3D dimensions, topology, roughness, transmission, lighting intensity, lens, easing or creator intent from RGB footage alone. Screen coordinates are not world coordinates. Preserve uncertainty codes from registry. Validate contradictions against exact source frames; log any revisions. Original source beats derived text; measured data beats manual estimates for the same quantity only if methods and ROI match. A proposed target is not evidence. No claimed score without a rubric and appropriate validation. Do not cite speculative causal hypotheses as established fact.
## Design controls
- Establish purposeful spatial architecture and local group alignments; protect functional information.
- Include multi-scale information: world, system, component, object, construction and microdetail.
- Use contrast between rectilinear/curved, rigid/flexible, smooth/textured, opaque/translucent, ordered/irregular and technical/expressive.
- Give every object a role, not merely a decorative label. Model depth when visible; use image textures for embedded photos, not unnecessary 3D faces.
- Animate meaningful changes; separate camera movement from individual object motion; transfer motion activity between regions. Keep irrelevant geometry stationary.
- Functional text and UI reflow independently; avoid scaling a screenshot when the source shows responsive layout.
- Lighting and material interactions must be plausible, directionally coherent and scale appropriate. Avoid universal bloom or uniform shadows.
- Reserve high saturation, motion and expressive shapes for focal contrast. Let spectacle alternate with comprehension.
- Use continuity of visual language; do not assume all shots share identical physical coordinates.
## Workflow gate
Do not start final rendering until the brief, shot list, object roles, scene layout, material strategy and motion dependencies are internally coherent. Apply the counterfactual audit to each hero object. For reconstruction, compare matched source frames with independent metrics. For creative transfer, use role-based evaluation rather than pixel similarity. Report failed tests and untested criteria. Never claim 95% rendering fidelity because this research scored 95% conceptually.
## Priority order
Source recording > inspected source frames > reproducible measured data > manually estimated data > interpretation > proposed implementation. Resolve discrepancies explicitly; never silently average inconsistent measurements.
