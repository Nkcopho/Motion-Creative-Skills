# Registry rules
objects.json is machine-readable; objects.csv is a flat equivalent. The 265 records include parent/child surfaces, grouped family records and shot-local aliases; this is not 265 proven distinct meshes. Null = not measured, not zero. Reference frame anchors a shot or visible object; some objects are visible elsewhere in the associated interval, check the footage. Prefixes: OP opening, ENV ground, AR architecture, ST stationery, TY typography, CT contrast, CL/CR swatches, UI layout, AV avatars, DC decorative, PC clips, TN tunnel, ML mail, RB ribbon aliases, EM email stack, RX reactions, TK task, CUR cursor, OUT ending, FN functional families. Use scenes.csv and behaviours.csv to retrieve relationships. Material ranges are proposed only. Missing exact timestamps, full masks, parent transforms and hidden surfaces must remain unresolved, not fabricated. All entries reflect the previous analyses rather than a fresh exhaustive segmentation. For production use the object contract to add actual proposed geometry and scene hierarchy. Maintain these IDs for reference; create new IDs for original assets.
