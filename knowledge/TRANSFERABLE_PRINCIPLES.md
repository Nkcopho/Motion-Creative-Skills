# Transferable principles and counterfactuals
| Principle | Application | Failure mode / exception |
|---|---|---|
| Meaning before objects | Assign semantic and compositional responsibilities before selecting forms | Literal prop substitutions can look generic |
| World not backdrop | Establish ground, local structure, depth, connected paths and continuation beyond frame | Do not force all shots to share coordinates; parallax unresolved |
| Six scales | World, system, component, object, construction, micro | More detail everywhere produces clutter |
| Controlled opposition | Rectilinear/curved, opaque/translucent, rigid/flexible, smooth/textured, order/irregularity, technical/expressive | Local irregularity within global order |
| Protected information | Reading space, stable UI and neutral surfaces where needed | Conclusion may concentrate detail in UI |
| Negative space as structure | Separation, optical spill, motion clearance, focus and reading | Not merely unused canvas |
| Material relationships | Directional coloured transfer, distinct shadow families, contact, thickness | Universal bloom or uniform shadows flatten the world |
| Geometry precedes information | Substrate -> layers -> glyph/text when semantically useful | Established UI may update content without geometry |
| Information determines geometry | Fixed-width responsive ribbon/inbox; semantic calendar heights | Screenshot stretching fails |
| Selective motion | Camera vs object, delayed settling, stagger and local activity | Simultaneous motion competes for attention |
| Focus supports meaning | Hero clarity, peripheral detail, readable holds | Aggressive camera useful during portals, not reading |
| Progressive disclosure | Occlusion, scale, nested portal and foreground reveal | Do not equate transitions with physical continuity |
| Colour scarcity | Local expressive warm accents within subdued scene | Coverage is not eye-tracking |
| Visual relief | Alternate spectacle, discovery, concentration and comprehension | Do not hold maximal density throughout |
| Counterfactual choice | Compare removal, replacement, alternate timing; test one variable | Untested alternative is a hypothesis |
